# 第三组特征实验：预登记（Pre-registration）

> 登记时间：2026-09-19（**在任何模型/回测运行之前**写成，之后不得按结果修改）
> 目的：把"试一试 AUM/费率/资金流"变成**可追责的少量假设检验**，避免在多规格搜索中
> 偶然找到"最佳方案"（数据窥探）。第二组已试 6 个相关方案、最高配对 NW 仅 +1.84，
> 因此第三组**预先只登记 4 个规格**，并对非基线规格做 **Holm 校正**、报告总试验数。

## 一、假设（先写清"为什么这份新信息在评分时能预测未来"）

1. **管理规模 AUM**：小规模基金在策略容量与打新/交易冲击上更灵活，但也更容易因规模过小而清盘；
   中等规模可能有规模效应。AUM 是**与净值历史无关的新信息**（不是 ret_12m 的变换）。
2. **费率**：费率是投资者付出的确定成本，也是基金公司/渠道动机的代理；在同类内，低费率
   通常对应指数化/被动倾向，高费率对应主动管理强度。净值已扣除管理费与托管费，
   所以费率**只能作为预测特征，绝不能在组合收益里再扣一次**。
3. **资金流**：净申购代表增量资金与热度，净赎回代表资金撤离与潜在清盘压力（赎回→迷你化→清盘）；
   它可能解释并**提前反映**动量信号的部分内容（追涨资金推动的动量更脆弱）。

## 二、固定规格（4 个，不再扩展）

| # | 规格 | 选股信号 | 说明 |
|---|---|---|---|
| S1 | **基线** | `ret_12m` 排序 | 与既有主策略完全一致（对照锚） |
| S2 | 动量 + AUM | `ret_12m` 与 `log(AUM)` 横截面标准化后等权合成排序 | 线性、可解释，不调权重 |
| S3 | 动量 + 费率 | `ret_12m` 与 `−管理费率` 前缀标准化后等权合成 | 低费率方向为正（假设 2） |
| S4 | **主规格**：动量 + AUM + 费率 + 资金流 | 四个分量横截面标准化后等权合成 | 唯一"主规格"，其余为消融 |

- 合成方式**固定为等权标准化**（不做网格搜索、不学权重）；所有分量在**当月截面**标准化（只用当时信息）。
- 选股：Top50 等权、每月调仓、持 6 月重叠、费用 申购 0.15% + 赎回 0.5%（与 v2 完全一致）。
- 研究池：**含清盘池**（`--include-delisted`，7071 只）；区间：dev 段（≤ 2025-02-28），各规格同区间对照。
- **holdout 不参与**（已看过，不得充当盲测）。

## 三、评价指标（全部预先固定）

对每个规格，报告：
1. **相对原动量的费用后配对差**（逐月差，NW(6) t）——主判据；
2. **相对可执行全池的费用后超额**（NW(6) t）；
3. **分 4 段年化方向**（等长切分，看是否稳定）；
4. 换手、最大回撤、年化波动；
5. 特征覆盖率（AUM/费率/资金流的可得比例，按年份）。

**多重比较**：非基线规格共 3 个（S2/S3/S4），对"相对原动量配对差"的 p 值做 **Holm 校正**，
并在报告中写明**总试验数 = 4**（含基线）。不因出现"某个规格显著"就重复换指标试。

**判定规则（预先写死）**：
- 若 S4（主规格）在 Holm 校正后仍显著为正（5% 水平）**且**相对可执行全池为正、风险换手未明显恶化
  → 记为"第三组有增量"，进入下一步（影子策略 + 更大样本验证）；主策略仍**不立即替换**。
- 若只有 S2/S3 之一显著 → 记为"单特征可能有弱信息"，不据此改动主策略。
- 若都不显著 → 结论为"在现有数据与口径下未检出增量"，按既定纪律**停在这条线**。

## 四、时间口径（用户 2026-09-19 指出）

- AUM 与资金流按**报告期 + 法定披露时限**转为 `available_date`（季报 +21 天 / 半年报 +62 天 /
  年报 +90 天；清盘期间的高频记录 +7 天），特征只使用 `available_date ≤ 截面 t` 的最新一期
  ——**不能把季度末规模当成季度末已经知道**。这是**规则化近似**（真实公告日可能更早，方向保守），
  已在 `src/fund_attrs.py` 注明；后续若需精确，可用 EID 逐只取定期报告公告日替换。
- 费率取**当前值**（历史变动少；与"基金类型取当前标签"同类的历史近似），该局限必须随结论引用。
- 清盘基金的费率/规模可能缺失（实测约 40% 清盘基金取不到费率）→ 缺失**不填补**，
  在合成时该分量视为不可用（只用可得分量），并单独报告覆盖率。

# Phase 4 前向纸面记账协议（2026-10-02 审计 P1-4）

**状态：协议已确定，账本尚未实现。当前 `ml/ledger` 只记录「目标权重 + 执行事实」，尚未计算任何可核验的前向绩效。**

本文件的作用是先固定"怎么记账、与历史口径如何区分"，避免首次 paper 确认后出现"悄悄换口径、再声称与回测一致"的问题。**不改动冻结策略**（`ret_12m` Top50、6 个月持有、申赎费 0.15%/0.5%）。

## 1. 必须先写清楚的口径差异（审计发现）

| 位置 | 现存表述 | 实际实现 |
|---|---|---|
| `live_portfolio.py` 顶部注释 | "在持 cohort 权重**不做月度再平衡**（自然漂移，与回测一致）" | 本模块只维护**建仓时的目标权重**，不计算收益，也不做份额漂移模拟 |
| `backtest_strategy.py` | 收益聚合 | 对各基金**当月收益求简单均值**，再对 cohort 求均值（等权算术聚合，**未**使用漂移后的份额权重） |

**两者不能声称"在六批 cohort 到齐后自动完全一致"。** 反例（两基金各 50%）：

- 第 1 个月：A 涨 100%、B 不变 → 真实份额权重变为 A 2/3、B 1/3；
- 第 2 个月：B 涨 100%、A 不变 → **自然持有（漂移）收益 = 1/3**，而**等权当月均值 = 1/2**。

历史回测成绩按等权算术口径产生，**不得**用漂移口径重算后宣称与既有结论一致；反之，前向纸面若采用漂移口径，必须与历史成绩**分列对账**并注明口径差异。

## 2. 前向账本规格（首次模拟成交时一次性固定）

1. **初始资本与成交要素**：固定初始资本；逐笔记录买入金额、成交净值、份额、`BUY_FEE=0.15%` 申购费、到期赎回 `SELL_FEE=0.5%`；现金部分按既定 **2%/年** 计息。
2. **收益口径**：一律使用**官方日增长率**（净值表 `日增长率` 字段）累计，**不得**改用累计净值 `pct_change`（分红除权口径不同）。
3. **可执行全池对照**：固定入池集合（入池日、数据时点、费用口径与主策略一致）；前五个月按 1/6 递进建仓，**现金差异如何比较必须单独说明**（历史 warm-up 用 `1/n_held` 等权、未建模现金，与前向方案 A 语义不同）。
4. **对照目标**：主策略检验的是**相对可执行全池**的表现；只有影子方案才检验"相对原动量的配对增量"。原动量不能以"比自己有增量"作为验收条件。
5. **统计纪律**：沿用既定冻结纪律与 **NW(6)** 自相关稳健 t 值；126 交易日标签、六个日历月 cohort、实际执行区间**分别记录**，不凭 "2027-03" 猜成熟。

## 3. 与执行确认的关系

- `confirm_execution` 只把 cohort 从 `planned` 改成 `active` 并写不可变执行事件——**不产生任何收益数字**；
- 在账本实现之前，任何"前向收益"结论都不成立，`portfolio_state.json` 里的 `cash_weight` / `target_weights` 只是**目标权重**，不是估值结果；
- 若长期只维护目标台账，须在每个运行记录里显式标注"**尚未计算可核验的前向绩效**"（本协议即为该标注依据）。

## 4. 首次前向复核时间点（沿用既定计划）

- 第一批 6 个月标签成熟（约 2027-03）时**仅查完整性**，不做绩效结论；
- 首次正式前向复核约 2028-02~03，按三条门槛 + NW(6) 执行，且必须在账本实现并冻结口径之后。
